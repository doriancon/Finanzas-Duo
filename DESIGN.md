# Duo Finance design system

<!-- impeccable:design-schema 1 -->

## Direction

A calm shared finance space: editorial headings, clear daily figures, four distinct currency cards, soft light surfaces and compact rounded controls. On mobile, a floating bottom bar keeps the main tasks within reach; desktop uses a dedicated sidebar and two-column home layout.

## Tokens

| Role | Value |
| --- | --- |
| Canvas | `#f8f7fb` |
| Surface | `#ffffff` |
| Primary text | `#201b2b` |
| Secondary text | `#8a8492` |
| Violet action | `#7744e8` |
| Budget lavender | `#ecdefe` |
| Mint activity | `#d8f0e7` |
| Dark navigation | `#221c2b` |

Display and key numbers use Manrope; supporting text uses DM Sans. Core cards use 18–25px radii, while controls use 10–16px. Shadows are offset and diffuse. Financial categories keep distinct colors in the interactive charts and lists.

## Behavior

The first viewport emphasizes balance by currency, quick movement entry and the one shared monthly budget. Business movements remain discoverable in the same history with an explicit Lencería label. The budget and statistics consume only everyday expenses in the selected currency. Reduced-motion preferences shorten transitions.

## Responsive

At desktop width, navigation is a sidebar with content columns. At tablet width, the sidebar becomes a floating bottom bar. At phone width, panels stack and the four-card currency carousel remains horizontally scrollable by touch, keyboard or arrow controls.
